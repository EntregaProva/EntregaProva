# Definition of Done (DoD)

Uma tarefa só é considerada pronta quando TODOS os itens abaixo são verdadeiros.

## Obrigatórios 
- [ ] PR revisado por alguém diferente do autor e CI verde
- [ ] Pelo menos um teste novo ligado a um critério de aceite
- [ ] Nenhum segredo (senha, chave, token) no código
- [ ] Telas com estado de carregando, vazio e erro
- [ ] Logs sem dados pessoais (nome, CPF, telefone, e-mail)
- [ ] Nenhum recurso novo no GCP sem ADR ou aprovação do Tech Lead

## Como verificamos
 O revisor só aprovara se todos os itens estiverem marcados.
